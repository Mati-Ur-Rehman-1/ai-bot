# AI Chatbot + OCR & Image Generation

A web-based AI assistant capable of:

-  **Chat:** Normal conversations using an AI language model  
-  **OCR & Translation:** Extract and translate text from images  
-  **Image Generation:** Generate images from text prompts  

The frontend is built with HTML/CSS/JS, and the backend interacts with AI models deployed on **Azure** using API keys. The project is deployed on **Azure Web App Service**.

## **Features**

1. **Chat Mode**
   - Real-time messaging with AI
   - Powered by Azure-hosted ChatGPT-like model  

2. **OCR & Translation Mode**
   - Upload images to extract text
   - Translate extracted text to multiple languages (English, Urdu, German, French, Spanish, Arabic)

3. **Image Generation Mode**
   - Generate images from textual prompts
   - Download generated images  

4. **UI/UX**
   - Responsive and modern interface
   - Typing indicator, smooth chat animations, and file upload feedback

---

## **Tech Stack**

- **Frontend:** HTML, CSS, JavaScript  
- **AI Models:** Azure OpenAI API (ChatGPT, DALL·E, OCR/Translation)  
- **Hosting/Deployment:** Azure Web App Service  


**Note:** This AI Bot is currently *not functional*. 
 
 * *Cloud Resources:* The Azure Web App service and associated resources have been decommissioned.
 * *API Keys:* All sensitive credentials and API keys have been revoked and removed from the project.
 
 This repository remains public for *portfolio and documentation purposes only* to demonstrate the codebase and logic.
